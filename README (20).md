# UK Traffic Analysis

Analysis of UK road traffic data to uncover accident trends, congestion patterns, and regional traffic flow using SQL, Excel, Power BI, and Tableau — delivering data-driven insights for road safety and traffic planning.

## 📌 Project Overview

This project explores UK traffic data to identify key patterns in accident severity, peak congestion times, vehicle types involved, and regional hotspots. The goal is to turn raw traffic records into clear, actionable insights through interactive dashboards and structured queries.

## 📂 Repository Structure

```
UK-Traffic-Analysis/
│
├── assets/       # Images, icons, and dashboard screenshots
├── data/         # Raw and cleaned traffic datasets
├── docs/         # Project documentation and reports
├── excel/        # Excel workbooks with pivot tables and charts
├── powerBI/      # Power BI (.pbix) dashboard files
├── sql/          # SQL scripts for data cleaning and analysis
└── tableau/      # Tableau (.twbx) workbooks and visualizations
```

## 🎯 Objectives

- Clean and structure raw UK traffic data for analysis
- Identify accident severity trends across regions and time periods
- Analyze peak traffic hours and congestion patterns
- Build interactive dashboards in Power BI and Tableau
- Surface key insights through SQL-driven queries

## 🛠️ Tools & Technologies

- **SQL** – data cleaning, aggregation, and analysis
- **Excel** – pivot tables, charts, and quick summaries
- **Power BI** – interactive dashboards and KPI tracking
- **Tableau** – advanced visual storytelling

## 📊 Key Insights

- Accident severity and frequency trends by region and road type
- Peak congestion hours and seasonal traffic patterns
- Vehicle type and driver demographic breakdowns
- Year-over-year trends in traffic incidents

## 🚀 How to Use

1. Clone the repository
2. Explore raw/cleaned data in the `data/` folder
3. Review SQL scripts in `sql/` for the analysis logic
4. Open the `.pbix` file in Power BI or `.twbx` file in Tableau to interact with dashboards
5. Check `docs/` for detailed write-ups and methodology
